# AI workspace

Эта папка хранит короткий контекст для coding-агента.

- `ARCHITECTURE.md` — текущая архитектурная идея проекта.
- `CURRENT_TASK.md` — одна текущая задача и критерии готовности.

Не добавляй сюда длинные журналы рассуждений, историю чатов и дублирующую документацию.

После завершения задачи:
1. обнови `CURRENT_TASK.md`;
2. если архитектура реально изменилась — кратко обнови `ARCHITECTURE.md`;
3. не расширяй документацию без необходимости.
