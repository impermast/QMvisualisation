# Current task

## Статус

Архитектура определена. Реализация нового core ещё не начата.

## Первая задача для агента

Изучи существующий проект и предложи минимальный план выделения нового ядра:

- `QuantumState`
- `QuantumSystem`
- одного простого visual object
- одной semantic animation

Ничего массово не переписывай.

## Что нужно вернуть

1. Какие существующие сцены/функции лучше всего использовать как первые источники кода.
2. Какие новые файлы предлагается создать.
3. Минимальные интерфейсы классов.
4. Один маленький пример сцены на новом API.
5. Какие части старого кода пока оставить нетронутыми.

## Ограничения

- Не переносить все существующие сцены на новую архитектуру.
- Не строить универсальный framework заранее.
- Не добавлять web/UI.
- Не создавать YAML/JSON DSL.
- Не добавлять сложный numerical solver без отдельной задачи.
- Перед реализацией сначала показать план пользователю.

## Definition of done

Задача завершена, когда пользователь одобрил план следующего минимального шага.
