# Визуализация квантовой механики и Телеграм-бот

Этот проект представляет собой набор скриптов для генерации анимаций, иллюстрирующих различные концепции квантовой механики, с использованием библиотеки `manim`. Управление генерацией видео и их отправка реализованы через Телеграм-бота.

## Возможности

*   **Визуализация квантовых явлений:**
    *   Туннельный эффект (`Tunneling.py`)
    *   Квантовый осциллятор (`Oscilator.py`)
    *   Потенциальная ступенька (`Ladder.py`)
    *   Расширение потенциальной ямы (`BoxExpansion.py`)
    *   Сжатые состояния (`Sqeeze.py`)
*   **Телеграм-бот:**
    *   Запуск генерации видео по запросу.
    *   Отправка готовых видео пользователю.
    *   Управление опросами.

## Установка

### 1. Предварительные требования

*   **Python 3.8+**
*   **pip**
*   **MiKTeX** или другая дистрибуция LaTeX (необходима для рендеринга текста в `manim`). Убедитесь, что `latex` и `dvisvgm` доступны из командной строки.

### 2. Настройка проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd QMvisualisation
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    venv\Scripts\activate    # Для Windows
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements_clean.txt
    ```

4.  **Настройте Телеграм-бота:**
    Вам понадобится токен для вашего бота. Убедитесь, что он доступен для проекта (например, через переменные окружения).

## Использование

### Запуск Телеграм-бота

Для запуска бота, который будет слушать команды в Телеграме:
```bash
python telegram_listener.py
```
Бот запустится и будет готов принимать команды.

### Локальный рендеринг

Для локальной генерации видео без участия бота вы можете использовать `main.py`.

1.  Откройте файл `main.py`.
2.  Выберите сцену для рендеринга, раскомментировав нужную строку:
    ```python
    # scene_to_render = Tunneling
    scene_to_render = Squeeze
    # scene_to_render = Oscilator
    ```
3.  Запустите скрипт:
    ```bash
    python main.py
    ```
    Готовое видео будет сохранено в папке `media/videos/1080p60/`.
