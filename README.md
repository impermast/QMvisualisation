# Визуализация квантовой механики и Telegram-бот

Проект сочетает два слоя:
- набор Manim-сцен и переиспользуемых модулей для визуализации квантовой механики;
- Telegram-бота для вспомогательной работы с материалами и отправки файлов.

## Возможности

*   **Визуализация квантовых явлений:**
    *   Туннельный эффект (`Tunneling.py`)
    *   Квантовый осциллятор (`Oscilator.py`)
    *   Потенциальная ступенька (`Ladder.py`)
    *   Расширение потенциальной ямы (`BoxExpansion.py`)
    *   Сжатые состояния (`Sqeeze.py`)
*   **Новый MVP-слой архитектуры:**
    *   `QuantumState`, `QuantumSystem`, `StateEvolution`
    *   визуальные объекты для 2D/3D отображения волновой функции
    *   примерные сцены для свободной частицы и рассеяния на ступеньке/барьере
*   **Телеграм-бот:**
    *   отправка сообщений и файлов;
    *   управление опросами.

## Установка

### 1. Предварительные требования

*   **WSL Ubuntu** или другая Linux-среда для основного workflow
*   **Python 3.12+**
*   **pip**
*   Системные зависимости Manim: `ffmpeg`, `pkg-config`, `latex`, `dvisvgm`

### 2. Настройка проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd QMvisualisation
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements_clean.txt
    ```

4.  **Настройте Телеграм-бота:**
    Вам понадобится токен для вашего бота. Убедитесь, что он доступен для проекта (например, через переменные окружения).

## Использование

### Запуск Telegram-бота

Для запуска бота, который будет слушать команды в Телеграме:
```bash
python main.py
```
Бот запустится и будет готов принимать команды.

### Локальный рендеринг

Для рендера сцены напрямую используйте `manim` из активированного окружения.

Примеры:
```bash
manim -ql example_scenes/free_particle.py FreeGaussianPacket
manim -ql --format=gif example_scenes/step_tunneling_minimal.py StepTunnelingMinimal
```

Готовые артефакты Manim попадают в `media/videos/` и по умолчанию не предназначены для коммита.

### Временные файлы

Временные артефакты локальной проверки, покадрового анализа и разовых тестов храните только в `media/tmp/`.
Не создавайте временные папки в корне репозитория. Содержимое `media/tmp/` не коммитится и должно регулярно очищаться после проверки.
